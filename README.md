# local-paper-ai

**Scan it, file it, shred it.** Turn household paperwork into searchable PDFs —
and know which originals you can finally throw away.

- 📱 Scan with any phone (Android, iOS) — no special app required
- 🔒 100 % local processing (OCR + classification), encrypted cloud backup
- 🗂️ Auto-named files: `2026-03-14_Finanzamt_Steuerbescheid.pdf`
- ✅ Per-document verdict: *may shred* · *keep original* · *keep until YYYY*
- 💤 Runs on a shared box (e.g. a Jetson) and only works when it's idle
- 🔁 Stored in several places: server, desktop, phone, any cloud

Built on [Paperless-ngx](https://github.com/paperless-ngx/paperless-ngx),
Syncthing and rclone.

> Status: design phase — see [the design](docs/superpowers/specs/2026-10-28-local-paper-ai-design.md).

> Retention rules are defaults, not legal advice.
